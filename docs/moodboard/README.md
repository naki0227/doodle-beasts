## 読み取った決まり

- 夕暮れから夜の、彩度を落とした色。灰青・苔の緑・骨のクリーム・錆・暗い赤。差し色は金。
- 遠景: 地平線の向こうに霞んだ世界樹のシルエット。手前に巨人の骨（肋骨のアーチ）、霧、湖、針葉樹。
- 大測輪の残骸（錆びた鉄の輪）、刻む者の石碑（読めないルーン）。
- 人物: つば広の帽子、外套、背負い袋、杖とランタン。ウルネス様式の組紐の刺繍。
- 生き物: ワタリガラス、牡鹿、リス、狼、八本脚の馬。体の一部に霜の結晶が残る。
- 金の駒（正二十面体）: 小さなかたちが新しい世界を生む。夜になると金や金継ぎの継ぎ目がかすかに光る。
- 記録帳: かたちを測り、絵に残す。
